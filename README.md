# Отчет по лабораторной работе 10.2 МОБПРИ
## Тема: Корутины и Flow в Android (Jetpack Compose)
## Выполнили Челяпов и Кузнецов
[Скрины приложения](photootchetlr10_2mobpri.docx)
## Цель работы
Изучить и применить на практике механизмы корутин (Coroutines) и асинхронных потоков (Flow, StateFlow, SharedFlow) в Android-приложении с использованием Jetpack Compose. Освоить запуск длительных операций, обработку ошибок, управление жизненным циклом и обмен данными между корутинами.

## Задачи
Реализовать базовые suspend-функции и запускать их из Compose UI с отображением загрузки.

Создать Flow, применить операторы преобразования и обработать ошибки.

Использовать StateFlow для управления состоянием счётчика и автоинкремента.

Использовать SharedFlow для передачи событий (ручных и автоматических).

Продемонстрировать различные способы обработки ошибок (try‑catch, catch в Flow, Result).

## Выполненные действия
### Часть 1. Базовые корутины
Создана suspend-функция simulateLongOperation(duration: Long): String с delay().

Создана suspend-функция calculateSum(numbers: List<Int>): Int с withContext(Dispatchers.Default).

В Compose-экране добавлены кнопки для запуска этих операций, индикатор загрузки (CircularProgressIndicator) и отображение результата.

Использованы rememberCoroutineScope(), scope.launch и управление состоянием isLoading.

### Часть 2. Flow
Реализована функция numberFlow(): Flow<Int>, эмитящая числа от 1 до 5 с задержкой 500 мс.

Реализована transformedFlow(flow: Flow<Int>): Flow<Int>, которая преобразует числа (квадрат чётных).

Реализован errorFlow(): Flow<String>, демонстрирующий оператор catch.

В UI добавлены кнопки для запуска обычного, преобразованного и ошибочного Flow. Все значения отображаются в LazyColumn. Сбор Flow выполняется через scope.launch с сохранением списка значений.

### Часть 3. StateFlow (счётчик)
Создан MutableStateFlow(0) с помощью remember, подписка через collectAsState().

Реализованы функции increment(), decrement(), reset(), incrementBy(5).

Добавлен автоинкремент: кнопка «Автоинкремент» запускает корутину, которая каждую секунду увеличивает счётчик. При повторном нажатии – отмена через Job.cancel().

Использован DisposableEffect для отмены автоинкремента при выходе из экрана.

### Часть 4. SharedFlow (события)
Создан MutableSharedFlow<String>(replay = 3) для передачи строковых событий.

Сбор событий выполнен через LaunchedEffect и collect(), последние 10 событий хранятся в mutableStateOf.

Реализована ручная генерация события и автоматическая генерация (каждые 2 секунды) с помощью scope.launch и while(true).

Автогенерация управляется через Job, отменяется в DisposableEffect.

### Часть 5. Обработка ошибок
Функция riskyOperation(success: Boolean): String – выбрасывает исключение при false.

Функция riskyFlow(): Flow<String> – эмитит шаги и выбрасывает ошибку, перехватываемую catch.

Функция safeOperation(success: Boolean): Result<String> – возвращает Result.success или Result.failure.

В UI добавлены четыре кнопки:
– успешная операция,
– операция с ошибкой (try‑catch),
– Flow с обработкой через catch,
– безопасная операция через Result.fold().

## Вывод
В ходе лабораторной работы были успешно освоены основные инструменты Kotlin Coroutines и Flow в контексте Android-разработки на Jetpack Compose. Практически закреплены навыки:

запуска suspend-функций из UI с управлением состоянием загрузки;

создания и преобразования холодных потоков Flow;

использования StateFlow как наблюдаемого источника состояния (счётчик);

применения SharedFlow для одноразовых событий;

обработки ошибок разными способами (try‑catch, catch-оператор, Result).

Полученные знания позволяют писать асинхронный, безопасный и реактивный код с чётким контролем жизненного цикла.
